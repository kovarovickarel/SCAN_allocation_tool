SCAN Google Sheets importer

This prototype imports the project-planning download into a new blank Google spreadsheet. It creates Resource Planning, Expenses Proj Spec and Site hourly rates, with native dropdown chips.

Download importer files (.zip)

Appearance: native Google Sheets tables create the chips and add table header controls. Project chip option colours may need a final adjustment in Google Sheets. The script has not yet been run in a signed-in Google account; this is the prepared prototype for that next step.

Set up a blank spreadsheet

  1. Download and unzip the importer files. Create a new blank Google spreadsheet.
  2. Open Extensions → Apps Script. Replace the contents of Code.gs with the downloaded Code.gs.
  3. In Apps Script, use + → HTML, name the file Import, and paste in the downloaded Import.html.
  4. Open Project Settings and enable Show “appsscript.json” manifest file in editor. Return to the editor and replace that manifest with the downloaded appsscript.json. This enables the Google Sheets advanced service. It should appear under Services as Sheets. If you use a custom Google Cloud project, enable its Google Sheets API as well.
  5. Save. Select showScanImport in the editor's function selector and click Run. Google will request authorization. The script needs spreadsheet access to use the Sheets API and display the importer. If company policy blocks authorization, ask your Workspace administrator; do not bypass the restriction.
  6. Return to the spreadsheet. The import dialog should be open. On later visits, use SCAN Import → Import planning file…; reload the sheet once if that menu is missing.

Export and import a project

  1. In SCAN, use the orange Export control next to View timeline.
  2. Choose the resulting .scan-planning.json in the Google Sheets import dialog, then click Import planning. Use this planning export, not a workspace JSON backup.
  3. The blank sheet is populated and renamed using the project, P1/P2 and export date/time. Source JSON files and the SCAN workspace are unchanged.
  4. Inspect the two planning tabs. Grey chips are expected in FTE C/D/G/J and Expenses B/C/F/I/L. Project chips are in FTE H/I and Expenses G/H. To match their option colours to the timeline, select those project-chip ranges, open Data → Data validation, edit the project's option colour and click Done. Google does not expose that option colour in the documented table API.

What it carries across

The download includes the calculated FTE and expense values, formulas, project milestones, date/colour bands, row heights, column widths, groups, initial hidden columns, frozen panes, merges and the site rates. Coincident milestone labels retain line breaks; row 3 keeps the standard row height you requested.

Before importing

The importer refuses non-empty spreadsheets and does not read or change other documents. If an import fails before completion, it attempts to remove only the tabs created by that attempt. Do not edit the destination while an import is running. Missing hourly rates stay unpriced and can be filled in Site hourly rates.

This is a local Apps Script installation, not a published or company-installed add-on. Once the prototype is reviewed in Google Sheets, it can be packaged for organizational distribution.

Planning-file format 1. No scripts, requests or formulas that fetch external data are accepted from the uploaded file.
